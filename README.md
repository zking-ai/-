项目概述

为大亚湾核电站设计开发高可靠性能耗监测系统固件，实现对核电站辅助设备（冷却系统、照明系统、办公设备等）的7×24小时连续精准监测。系统需满足核电站严格的安全标准和数据完整性要求，确保在复杂电磁环境和长期运行下的稳定可靠。

核心功能需求
1. 高精度能耗监测与计算
实时采集三相电压（0-400V）、电流（0-100A）信号，测量精度要求±0.5%
计算有功功率、无功功率、视在功率，支持谐波分析（最高31次谐波）
实现电能积分算法（Wh/kWh），支持正向/反向电能计量
温度补偿算法，确保-20℃~+70℃全温度范围内的测量精度

2. 核电站级数据安全与完整性
CRC32+双备份存储策略：累计电量数据掉电不丢失，满足核电站数据完整性标准
冗余通信机制：支持Wi-Fi + 有线以太网双通道热备，自动切换
数据加密传输：TLS 1.3加密，符合核电站网络安全规范
操作审计日志：所有配置变更、异常事件完整记录，留存周期≥5年

3. 极端环境可靠性保障
工业级EMC设计：通过核电站强电磁干扰环境测试（IEC 61000-4系列）
宽温域工作：-40℃~+85℃稳定运行，满足核电站全场景部署
防辐射加固：关键元器件满足核电站辐射环境要求
7×24小时连续运行：MTBF（平均无故障时间）≥100,000小时

4. 智能网络管理与自愈
双状态机设计：Wi-Fi连接状态机 + MQTT会话状态机独立管理
智能重连策略：基于信号质量的指数退避重连算法
离线缓存机制：网络中断期间数据本地存储，恢复后自动补发
心跳保活与健康上报：30秒心跳间隔，异常状态主动上报

5. 远程维护与安全管理
A/B分区OTA升级：支持远程固件升级，失败自动回滚，防止升级变砖
数字签名验证：固件包强制SHA256签名校验，确保来源可信
多级权限管理：区分操作员、工程师、管理员三级权限
远程诊断接口：支持远程读取运行状态、调试日志、故障诊断

6. 核电站专用功能
同步对时功能：支持NTP/PTP时间同步，确保全网设备时间统一
事件顺序记录：SOE（Sequence of Events）功能，时间分辨率≤1ms
阈值联动告警：可配置多级阈值，触发声光报警或联动控制
Modbus TCP兼容：与核电站现有DCS系统无缝对接




数据保存时间：掉电后≥10年



通信性能参数指标要求

Wi-Fi标准：
IEEE 802.11b/g/n

通信距离：
≥200m（视距）

1s~24h可配置

≥1GB（满足30天数据缓存）

≤10s（从断线到重连成功）

系统架构要求
硬件平台
主控制器：Bouffalo BL808三核RISC-V处理器
存储：16MB Flash + 8MB PSRAM
ADC：16位同步采样ADC，采样率≥100kSPS
通信接口：Wi-Fi 2.4GHz + 10/100M以太网 + RS-485
电源：宽电压输入（85-265V AC），备用超级电容

FreeRTOS多任务架构：
├── 高优先级任务（1ms周期）
│   ├── 采样任务：ADC数据采集
│   └── 保护任务：过压/过流/断线检测
├── 中优先级任务
│   ├── 计算任务：功率/电能/谐波计算
│   ├── 存储任务：双备份数据存储
│   └── 网络任务：Wi-Fi/MQTT状态管理
└── 低优先级任务
    ├── 诊断任务：健康状态监测
    ├── 日志任务：本地/远程日志记录
    └── OTA任务：固件升级管理
数据流设计
复制
传感器 → ADC采样 → 数字滤波 → 瞬时值计算
         ↓
实时数据库 ← 电能积分 ← 功率计算 ← 有效值计算
         ↓
本地存储（双备份）    网络传输（加密）
         ↓           ↓
掉电恢复    云平台/核电站监控中心
